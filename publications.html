Layout: compact — title on one line, authors on one line, then a single "meta" line with venue + year + DOI + OA pill (or RG link), optionally followed by media-coverage pills. {%- endcomment -%} {% assign raw_pubs = site.data.publications %} {% if raw_pubs %} {%- comment -%} IMPORTANT: do NOT use Liquid's `sort` on the pubs array here. Liquid's `sort` is backed by Ruby's Array#sort, which is NOT stable — it silently reshuffles papers that share a year, so the ▲▼ reorder in the widget would stop matching the page. Instead we iterate `raw_pubs` in its exact YAML order and use `where: "year", y` to pull out each year's papers. The `where` filter preserves original order, so within-year order comes straight from the YAML.
